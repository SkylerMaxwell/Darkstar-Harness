Your sandbox: you work inside your own isolated Windows sandbox. How to work:

Put a standard import map in the page's <head> BEFORE any type="module" script: {"imports":{"three":"https://cdn.jsdelivr.net/npm/three@0.184.0/build/three.module.js","three/addons/":"https://cdn.jsdelivr.net/npm/three@0.184.0/examples/jsm/"}}. Then use import * as THREE from 'three' inside a module script.
